# Spegeln

Spegeln is a Swedish platform for authority scrutiny, public insight,
coordinated civic action and AI-supported workflows.

This repository is a public documentation mirror. It contains product
descriptions and updates, with source code, prompts, datasets, connector
internals and deployment configuration kept in the private repository.

## Snapshot

The founder-approved product is an open beta. Each workflow must show whether
it is built, partly built or planned; this description does not establish that
every external provider or production integration is connected.
(FD-044, FD-107, FD-109)

The eight modules are authority and official profiles, coordinated
administrative action, tax planning, authority failure reports, the people's
court, the weaknesses wiki, reverse surveillance and automated appeals.
The product has Swedish and English workspaces. (FD-043)

## Product Shape

- Verified public records publish automatically with their sources.
  Uploaded evidence receives AI labels and the founder's specified exception
  handling before automatic publication. Suspected manipulated media follows
  the separate authenticity check. (FD-008, FD-010, FD-011)
- Unsubstantiated anonymous claims are visibly labelled and never count as
  evidence. Legal review advises on risk and corrections without stopping
  publication. Proven errors are corrected openly. (FD-012, FD-015, FD-045,
  FD-047)
- Reporting supports anonymous and pseudonymous participation. The app stores
  no IP addresses or raw device data about anonymous tipsters; case tokens and
  normal operational minimum remain. Providers' short security logs are
  minimized. Private originals, public derivatives and public claims remain
  distinct. (FD-120, FD-199)
- Administrative action uses the user's chosen scope without a fixed platform
  cap on recipients or volume. Delivery state, payment and failures remain
  visible. Starting an automated appeal job authorizes its creation and
  delivery without further approvals. (FD-017, FD-018, FD-068)
- AI performs the designated analysis and drafting tasks. If all approved AI
  routes fail, work is queued with a visible status. (FD-174, FD-196)
- Anyone can register a free API key directly for public data. Premium access
  activates automatically after payment; it does not require a separate manual
  partner review. (FD-098, FD-172)

These are product rules. Available data and connected services must be checked
in the product's status view. (FD-109)
