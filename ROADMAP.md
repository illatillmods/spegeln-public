# Public Roadmap

This roadmap describes product priorities without publishing private strategy,
source details or implementation tactics.

## Current Product Contract

Open beta, available to everyone. Each function must identify whether it is
built, partly built or planned. Product rules do not prove that every production
integration is connected. (FD-044, FD-107, FD-109)

Focus areas are completing and verifying external provider connections,
end-to-end workflows and the accuracy of public availability labels. Publication,
privacy, civic action and API behavior follow the active founder decisions.
Legal review advises without becoming a publication veto. (FD-045)

## Planned Feature

Relevant public detail pages are planned to offer a relevant Flashback discussion
or a focused search when the match is uncertain. Forum discussion remains
external and unverified and never affects facts, evidence, votes or indexes.
This is planning issue #29, not a connected feature. (FD-008, FD-012, FD-109;
explicit founder instruction of September 4, 2026)

## Public Material

Screenshots and examples need review for private data and sensitive operational
context before publication. Benchmarks and security certifications require
supporting evidence before being claimed.

## Not Planned For This Mirror

- source code publication
- prompt publication
- datasets or connector implementation details
- infrastructure configuration or private operational notes

The existing all-rights-reserved notice remains in force.
